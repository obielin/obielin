I am a machine learning engineer and statistician, and a Fellow of the Royal Statistical Society (FRSS), with more than a decade of experience in data and machine learning. I have worked across the UK public sector and regulated industries, and I co-founded IdentArk. I build open-source tooling for AI agents: security scanning, audit trails and reliability testing, in Python, TypeScript and Java.

## IdentArk

IdentArk isolates credentials from AI agents. The agent holds a session ID, and the control plane holds the credential and makes the call.

Role: Co-Founder and Director of Governance, Risk and Compliance.

## Open source I maintain

| Repo | What it does | Install |
|---|---|---|
| [skillshield](https://github.com/obielin/skillshield) | Scans AI agent skills for prompt injection, data exfiltration and malicious payloads before you install them. | `pip install skillshield` |
